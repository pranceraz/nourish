# P3 meal drafts

Prioritize ordinary ingredients and prepared dishes. Ship a searchable USDA survey-food catalog on the device. The user can build a meal without any key. A connected backend may identify ingredients from text or a meal photo. Return estimated gram weights, assumptions and USDA candidates for review.

Show editable ingredient matches and quantities plus a combined total. The default save mode is Ingredient breakdown. A toggle switches to Complete dish. Both modes use the same reviewed portions and preserve their sources. Apply all writes for a meal in one transaction. Vitamins and minerals retain units, unknown values and per-entry snapshots. Users choose visible nutrients and personally approve proposed targets with effective dates.

Settings supports an optional user-owned USDA key for a read-only GPT lookup tool. Store the key encrypted on the configured backend for that user. Keep the device's app access credential in Keystore-backed storage. The Android app can set, replace, check presence or remove the USDA key. Only the separately authorized MCP lookup uses it. Full ChatGPT account linking and diary synchronization follow in P4.

Use licensed Inter for body text, labels, buttons and input; retain the Bricolage display hierarchy.
