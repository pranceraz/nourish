# P2 input accelerators

The pink + opens local food search, manual entry, meal photography and package scanning. Search saved labels by name or GTIN. The installed provider is the user's own Room catalog. The user chose to enter an unfamiliar product's label once and remember its barcode upon Save. Repeated scans open an editable portion with the saved nutrition. Cancel leaves the catalog and diary untouched.

Use the system camera for meal pictures and retail barcode photographs, the system photo picker for existing images, and digit entry as the scanner fallback. The app requests no camera, broad photo-library or network permission. A photo belongs to the individual diary entry. Store an oriented, reduced-size JPEG without original metadata in the private database, preserve it on edits and duplication, and delete it with its entry. Photos provide visual context for manual entry. AI nutrition drafts remain P3.

Verify upgrading a populated P1 database, GTIN matching and invalid check digits, external camera/picker results including cancellation, saved label reuse, attachment persistence, and the previous offline restart flow.
